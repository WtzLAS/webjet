0.4.0 regrouped webjetctl by scope (user decision, clean break, no aliases; 0.3.0 had merged the CLI, 0.4.0 regrouped it):
- `webjetctl network …`: `config` (show|check|apply|edit|get|set|unset of the network configuration), `account`, `node`, `controller`, `psk`, `camouflage`, `submit` — signed with an account key, submitted via the local agent.
- `webjetctl local …`: `init --genesis`, `enroll <string>` (both `--config/--data-dir`), `status`, `peers`, `sessions`, `metrics`, `ping`, `inject`, and `config [--node NAME]` (same verbs; the node's own config, owner or admin; `show --effective` shows what's in force).
- `webjetctl root --dir … <cmd>`: offline root/emergency keys (code in `crates/webjet-tools/src/root.rs`, `RootCmd`, run with `spawn_blocking`), unchanged.
- Global flags `--socket/--keys/--account/--json` work at any position. The old top-level `policy|dns|seeds|limits|transport` (YAML) commands are gone; serde_yaml remains only for webjetctl's generic `print` output.
- `webjetd`: only `run` and `signer` (`--key`, `--socket`), plus hidden Windows `service` (service manager entry point). Before 0.3.0: `webjetd init/enroll`, separate `webjet-root`/`webjet-signer`.
- `webjetup` owns the Windows service: `sc.exe create webjetd binPath= "\"…\\webjetd.exe\" --config \"…\" service" start= auto depend= W32Time/Dnscache`, plus description and failure actions; removal does `sc.exe delete` and clears NRPT rules with comment `webjet`; deletes retired programs (`RETIRED_PROGRAMS`). `webjetup enroll` picks the command by installed version: <0.3 `webjetd --config C enroll`, 0.3.x `webjetctl enroll --config C`, ≥0.4 `webjetctl local enroll --config C` (`layout::before_0_3`, `before_0_4`).
- Release archives contain webjetd and webjetctl only (plus wintun.dll on Windows); `PROGRAMS = ["webjetd", "webjetctl"]`.
- Docker: entrypoint runs `webjetctl local init`/`local enroll` on first start; signer container command is `webjetd signer --socket … --key …`; healthcheck `webjetctl --json local status`; `WEBJET_RELAY_CAPACITY_MBPS`/`WEBJET_RATE_CEILING_MBPS` were removed (entrypoint dies with a migration hint).
- Scripts (local-net, cluster-test, soak-test, docker e2e/deploy/webjetup/runbook/tpm tests) and all docs use the new commands.
