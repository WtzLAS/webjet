Automatic Raft membership (0.7.0, on by default) was added so admins no longer run `controller add-learner/promote`.
- Pure planner: `crates/webjet-core/src/membership.rs` has `plan()` (one change per round) and `target()`. Order of steps: remove stale members (revoked node, `control` role lost, or cert gone while the leader's own cert is valid), add valid controllers as learners (skipping those in `Machine.removed_by_admin`), demote a dead voter when a healthy learner exists, then fix the count to an odd number ≤ `voters` (default 5). Promotion goes to the earliest-joined healthy learner (heard within 30 s, lag ≤ 64).
- The leader calls it from `leader_duties` → `Controller::auto_membership` in `crates/webjetd/src/controller/mod.rs`. It proposes `AutoMembershipEntry` (new EntryPayload in webjet.fbs), which `classify_entry` maps to a ConfChange. Replicas apply it through `Machine::change_members`, the same checks as a manual `ChangeMembership`, plus "refused when off".
- `Machine.member_since` (join log index) and `removed_by_admin` are kept in ControllerSnapshot (`member_since`, `removed_by_admin` in wire.fbs).
- Settings: `[controllers] auto_membership / voters (1,3,5,7) / dead_voter_after_s (0 or ≥60, default 3600)` in the network config. This is a new leaf kind `CONTROLLERS`=10 (msg type 28, ControllerSettings), written only when the document contains the section, so older controllers don't diverge. `show` doesn't spell it out and lists the built-in values in a comment instead.
- Rolling-upgrade gate: the EndpointRecord feature `auto-membership`. The leader changes nothing until every reachable member, and the node being added, advertises it.
- Raft accessors added: `conf_change_pending`, `silent_for`, `leader_for`, `match_of`.
- Remote `controller list` on a non-controller now prints hex IDs via `remote_status_json`, instead of the b0..b3 struct.
- Tests: membership unit tests, statemachine `automatic_membership_entries` / `controller_settings_leaf`, config `controller_settings`. `scripts/cluster-test.sh` and `docker/runbook-test.sh` now rely on automatic promotion.
