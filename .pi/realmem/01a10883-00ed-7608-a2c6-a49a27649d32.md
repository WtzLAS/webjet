In `crates/webjet-core/src/store.rs` `build_view`, an account tombstone replaces the account's leaf, so a revoked admin vanishes from `v.accounts`; the old issuer check `v.accounts.get(&issuer).map(..).unwrap_or(false)` therefore made every normal account the admin created invalid even with `revoke_issued = false`, contradicting §13.4. Fix: if the issuer is absent but in `v.tombstoned_accounts`, its accounts stay valid unless the issuer is in `revoke_issuers`. Found by docker/runbook-test.sh section 1.3 (carol revoked, dave must stay); unit test `statemachine::tests::admin_revocation_and_account_rekey`.
