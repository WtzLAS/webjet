`crates/webjetd/src/keystore.rs`: `[key] storage = auto|tpm|keychain|dpapi|file`. Ed25519 can't be signed by TPM/Secure Enclave, so the 32-byte seed is sealed at rest and decrypted into mlock'ed memory (core dumps disabled). `identity.key` format `WJK2 || backend || payload`; bare 32-byte file = legacy plain key. auto: TPM on Linux if usable (tpm2-tools), System keychain on macOS (needs root, else falls back), DPAPI machine scope on Windows; auto falls back to file with a warning, explicit backend must work. Sealed keys are device-bound: restored on another machine → refused with "re-key this node". Backend is fixed when the key is written (init/enroll/re-key). Keychain path untested so far (macOS runs weren't root).
