gpui 0.2.2 drops macOS NSEventTypeMagnify, so trackpad pinch did nothing. Webjet patch (redo after updating vendored gpui; listed in vendor/README.md, `Webjet:` comments): `vendor/gpui/src/interactive.rs` adds `PinchEvent {position, delta (= NSEvent magnification), modifiers, phase: TouchPhase}` (MouseEvent) + `PlatformInput::Pinch` (in mouse_event/keyboard_event); `window.rs` `dispatch_event` sets mouse_position/modifiers for it; `platform/mac/window.rs` registers `sel!(magnifyWithEvent:)` → handle_view_event; `platform/mac/events.rs` maps `NSEventTypeMagnify`. No element method — listen via `window.on_mouse_event::<PinchEvent>`.

webjet-app (`crates/webjet-app/src/ui/nodes.rs`): bottom `edges_canvas` takes `Listen {app, dragging}`, inserts a Normal hitbox in prepaint and registers a PinchEvent listener gated on `hitbox.should_handle_scroll`; `WebjetApp::pinch_graph` does `viewport.zoom_at(1 + delta, pointer)`. Windows precision touchpads send pinch as Ctrl+wheel (already zooms). Test: `ui::tests::every_tab_renders` simulates a PinchEvent.
