Its host-key was added to ~/.ssh/known_hosts on 2026-10 (ED25519 SHA256:ENU0wldqRqNfP428aWvZRiOehZVwxFhisfYahylfPYg). The builder images (webj8-internal/webjet-builder:4 etc.) live in the `docker_dind` container's daemon, not the host's: run with `docker exec docker_dind docker -H tcp://127.0.0.1:2375 run …`. dind only shares /var/lib/docker with the host, so copy sources in first: `rsync -az --exclude /target --exclude '/target-*' --exclude /dist --exclude /.pi/tasks ./ root@10.4.0.9:/root/webjet-apptest/`, then `docker cp /root/webjet-apptest docker_dind:/work/webjet` and mount `-v /work/webjet:/src` (plus a named volume for /usr/local/cargo/registry).
