Phase 4 (DoS/unbounded-growth limits, commit b7efb97) and Phase 5 (hot-path caches/performance, commit 61a3da9), 2026-10, both on top of 080fbf9; split by hunk from one working tree and committed without running checks at user's request (b7efb97 alone never compiled). Phase 5 invariants:
- webjetd node.rs `best_hop`: cached per peer in `Node.best_hops` (RwLock) for BEST_HOP_TTL=1 s; `forget_best_hop(peer)` MUST be called wherever a hop is inserted into/removed from `Node.hops` (register_hop, hop_down, test_hop). Uncached choice is `choose_hop`.
- e2e.rs `pick_circuit`: reuses `Inner.picked` for PICK_TTL=250 ms unless `LocalCircuit.live.removed` (set in circuit.rs `Table::remove_entry`) or out_label is None; `on_circuit_closed` clears it. `choose_circuit` is the old logic.
- `e2e::on_frame(n, c, buf: Vec<u8>, at, ecn)` takes the relay frame buffer and offset; decrypts with `SessionKey::open_owned(buf, at)` (in place).
- webjet-core store.rs View: `host_routes` (HashMap for /32,/128) + `ip_routes` sorted longest prefix first (`node_by_ip` takes the first match; anything editing ip_routes must keep that order); `any_relay` precomputed (gossip `is_core`). `build_view` decodes each leaf once; account leaves cached by leaf hash in a static (`decode_leaf`, 65536 entries, cleared when full).
- merkle.rs Tree: `bucket_hashes: Vec<OnceLock>` per first path byte, invalidated in `changed()`; root = buckets hashed up 8 levels. Proptest `cached_buckets_match_a_full_rehash`.
- conntrack.rs: `by_peer` index (proptest `check` verifies it), full-table sweep at most 1/s (`sweep_when_full`), `evict` removes global_cap/64 at once (expired first, then evict_rank, then oldest).
- frames.rs ReplayWindow clears whole words; the loop counts down (`left`) because counters near u64::MAX overflowed `x += n` (found by fuzz smoke test, regression test `replay_window_at_the_counter_limit`).
- webjet-net kcp/mod.rs: up to 4 `recv_loop` tasks per UdpEndpoint (`recv_tasks()`), so session creation is check+insert under one `sessions` guard (`spawn_session` returns None if (peer,conv) exists; `start_session_locked`). Idle sessions tick every 100 ms (IDLE_TICK), busy 5 ms. snd_buf ACK lookup by `partition_point` with `diff()`. tls.rs: static provider/algs, `certified_key` cached per public key.
- Controller: blocking work wrapped in `blocking()` = `block_in_place` on multi-thread runtime (run tick, propose, on_raft, maybe_sign_head), not a dedicated thread.
- webjet-app: `snapshot: Option<Rc<Snapshot>>`; Merkle refetched only when `status.tree_version` != `merkle_version`; metrics parsed only when text hash changes; first layout > SYNC_LAYOUT_MAX=40 nodes goes through `layout_job`.
- Benchmark result (M-series, data_path_cost): send 1356–1450 → 1286–1419 ns, receive 1343–1353 → 1315–1323 ns; AEAD dominates.
