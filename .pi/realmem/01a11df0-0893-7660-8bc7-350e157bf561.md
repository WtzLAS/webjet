In GPUI 0.2.2 (vendor/gpui `Interactivity::paint_scroll_listener`), every element with `overflow_y_scroll` under the pointer applies the wheel delta in the bubble phase and never calls `stop_propagation`. So a scrolling list inside a scrolling column scrolls both. Fix in webjet-app: `nested_scroll(id, &ScrollHandle)` in crates/webjet-app/src/ui/mod.rs is `scroll(id).track_scroll(handle).on_scroll_wheel(..)`, and the handler calls `cx.stop_propagation()` while `handle.max_offset().height > 0`. Bubble listeners run innermost element first, so the list scrolls and the outer column never gets the event. A list that shows everything (max_offset 0) still lets the outer column scroll. It is used for the Nodes tab's `node-list` (handle `WebjetApp.node_list_scroll`) inside `node-side`. Test `ui::tests::the_node_list_scrolls_alone` fails without the fix (checked).
