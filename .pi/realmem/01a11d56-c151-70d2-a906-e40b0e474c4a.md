`scripts/gpui-vendor-check.sh` (commit 1d72b1c) compares the `[package] version` of vendor/gpui and vendor/gpui_media with the newest non-prerelease, non-yanked version in the crates.io sparse index (`https://index.crates.io/gp/ui/gpui`). It exits 1 if crates.io is newer, 2 on errors. With `--hook` it only warns, uses a 5 s timeout, stays silent offline, and caches the answer for a day in `$(git rev-parse --git-path gpui-vendor-check)`. `.githooks/pre-commit` runs it with `--hook`. Each clone enables the hook once with `git config core.hooksPath .githooks` (set in ~/Projects/webjet). To skip it: `WEBJET_SKIP_GPUI_CHECK=1` or `git commit --no-verify`.
