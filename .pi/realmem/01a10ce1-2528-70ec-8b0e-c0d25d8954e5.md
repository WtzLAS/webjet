v0.6.0 is an annotated tag on commit 058aa0e, pushed to origin main on Forgejo. Since v0.5.1 it includes reverse proxy ports, compression (zstd/LZ4), the webjet-app Config tab and movable panes, the KCP immediate-flush latency fix, the e2e probe echo fix (64→128), FEC loss feedback, KCP retransmit counting, route e2e metrics and TunMetrics. The version that introduced compression is now called 0.6.0; the earlier docs/code said "0.5.2" and that was changed. The ops guide says to upgrade controllers first for compression and for `[[proxy]]` rules. Before tagging, `docker/webjetup-test.sh` passed. The macOS assets still have to be uploaded by hand after the CI release job: `scripts/release.sh v0.6.0 --publish --targets "aarch64-apple-darwin x86_64-apple-darwin"`.
