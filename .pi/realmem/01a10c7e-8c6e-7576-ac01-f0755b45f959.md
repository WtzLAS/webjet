The user decided (2025-10) how Webjet compression works:
- Control plane (HopControl gossip/Raft/snapshot messages): zstd (the `zstd` crate / zstd-sys C library is acceptable), always on by default.
- Data plane (e2e DATA/PROXY frames): LZ4 (`lz4_flex`), compresses each packet on its own, OFF by default and opt-in, because compressing before encrypting leaks through packet lengths (VORACLE/CRIME).
- Setting: network-wide in the TransportConfig, with per-node overrides in NodeConfig (not per policy/tag).
- Peers advertise support so mixed-version networks keep working; secrets (PskInfo, CamouflageSecret) are never compressed; decompression has a hard size cap.
