Since commit 31a5e6f, `crates/webjet-net/src/kcp/mod.rs` `run_session` keeps only the `tokio::select!` I/O loop (user stream, lane keys/records, datagrams, pending writes, wake timer).

**Protocol state** lives in `struct Session` (kcp, fec enc/dec, Bbr, rate, Pacer, Delivery, held_ack, loss-report counters). Its methods:
- `us()`, `room()`
- `on_datagrams(batch)`
- `input_shard`
- `lane_stats`
- `measure(now)` (RTT, retransmits, delivery → BBR, window)
- `async flush(now)` (pacing, raw/held acks, FEC shards)
- `async report_loss(now)` (STATS)
- `next_wake(user_pending)`

**Other pieces:**
- `struct Wire {ep, peer, stats}` with `async send(inner)` (seals and counts `wire_tx`).
- `type HeldAck = (Vec<u8>, Instant, Instant)`.
- `fn shard_datagram(held_ack, opened, conv, shard)` piggybacks a held ack (SHARD_ACK).

**Same commit, other files:**
- webjetd `dataplane::refresh` → `Local::of` + `prune_gateway_choices` / `serve_gateways` / `sync_routes` / `sync_dns` / `reevaluate_flows`.
- `outbound` → `serve_dns_query` / `gateway_return` / `admit_outbound`.
- `proxy::client_packet` → `known_flow` / `open_flow` (`Result<(), String>`; refusals are counted in the caller) / `policy_allows`.
- `metrics::build_report` → `route_metrics` / `link_metrics` / `rule_hits` / `limit_hits` / `alarms` / `tun_metrics`.
- `agent::connections` → `wanted_peers` / `dial_seeds` / `save_relay_cache`.
