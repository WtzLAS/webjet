Since commit cde8547 (2026-10, Phase 6), webjetctl is no longer one 2.2k-line `src/bin/webjetctl.rs`. It is `crates/webjet-tools/src/bin/webjetctl/`:
- `main.rs`: main, `network` dispatch, tests (clap `debug_assert`, `pick_ip`)
- `cli.rs`: all clap types
- `agent.rs`: key_dir, load_account, call/submit, node and account lookups, `pick_ip`, ticket
- `output.rs`: print/report/print_table
- `conf.rs`: network and local config
- `local.rs`, `account.rs`, `node.rs`, `rollout.rs` (remote upgrades), `controller.rs` (camouflage, controller, site_bundle)

Items are `pub(crate)`; each module uses `crate::{other modules::*}`.

Signed operations shared with webjet-app live in `webjet_tools::ops`: rename_node, revoke_node, set_tags, psk_epoch, rotate_psk (fails on a missing or last epoch), log_request, snapshot_request. A replaced key's account is found with `Account::adopt_network_id(&accounts_json)`; webjetctl's load_account and the app's sign_in both use it.
