Post-0.10.1 probe-traffic redesign (commits 3478887 probe-traffic cut, f2a5cce memories, 35017d7 version bump + install refs + ops guide 3.3 upgrade note "0.10.2 needs no order"), released as annotated tag v0.10.2 at 35017d7 pushed with main; docs refer to "nodes before 0.10.2" for the old probe/keepalive behaviour. Architecture updated in §11.2/§11.4/§9.4.3/§17.6 (uncommitted at the time).

Keepalives (node.rs, 1 s tick): only the dialer (hop.outbound) sends, flag KA_ONE_SIDED; interval KEEPALIVE 2 s for first 30 s / lossy >1% / last unanswered, else KEEPALIVE_SLOW 5 s. Accepting end answers, sets Hop.peer_keeps; sends own only if none by 2×KEEPALIVE into hop (old peer) or none for 12 s. One-sided keepalive carries observed_addr every 12th; receiver derives clock offset from wall_ms + srtt/2; KeepaliveAck.digest carries answering edge node's digest. Meter read every 2 s. Node::test_hop_dir(peer, transport, outbound).

Probes (paths.rs on_probe/on_probe_ack/send_probe/probe_now, circuit.rs Live.{next_probe,passive,last_reply}, PROBE_FAST/PRIMARY/BACKUP 1/5/15 s, PROBE_WARMUP 3, PASSIVE_SILENCE 20 s, route_tag()): source-only slower compact e2e probes Probe{route_tag, sent_at_us(=seq), echo_us, held_us}; answer {route_tag, sent_at_us, reply_at_us}; destination goes passive on new-format probe, measures RTT via LinkStats::on_rtt. Old-format probes (route_id set) answered as plain echo. Probe timing uses tokio Instant (paused-time tests). e2e on_frame: PROBE/PROBE_ACK no longer update last_used; probes no longer count as session use.

KCP (kcp/mod.rs): K_SHARD_ACK=6 (held[4]||acks_len[2]||acks||shard), STATS flag STATS_SHARD_ACK=2; lone small ack (≤2×24 B) held ≤ ACK_HOLD 10 ms to ride on a shard (sparse STATS). STATS every 1 s while loss in last STATS_QUIET 10 s, else every 10 s. Small-packet padding 0–31 B (gate.rs).

Schema appended fields: Probe.{route_tag,reply_at_us,echo_us,held_us}, Keepalive.{flags,observed_addr}, KeepaliveAck.digest.

Tests in crates/webjetd/src/probe_traffic.rs (#[cfg(test)] mod in lib.rs): keepalives_per_hop (real node::keepalive + node::handle_control, pub(crate), on test_hops with start_paused), probe_record_sizes, ignored wire::wire_cost (cargo test -p webjetd --lib probe_traffic -- --ignored --nocapture, WEBJET_PROBE_SECS); e2e::handshake_tests::probe_traffic_on_an_idle_circuit runs paths::run both ends; webjetd dev-dep tokio test-util; documented docs/development.md "Probe traffic".

Measured (wire::wire_cost, full agents, loopback): idle KCP hop 2.5 dgram/s ≈480 B/s each way → 0.4–0.7 dgram/s ≈130–150 B/s; TCP 165 → 85 B/s. Per in-use idle circuit e2e probe records 208 B/s per end → ~25 B/s.
