Nodes graph (crates/webjet-app/src/ui/nodes.rs + graph/): `graph::Viewport { pan, zoom }` in fractions of the drawing area (to_view/to_graph/zoom_at around pointer, zoom 0.2–8). WebjetApp holds `viewport`, `pinned: BTreeMap<node id,(x,y)>` (re-applied by `Graph::pin` after every refresh), `drag: Option<Drag>` (Pan or Node(id), 3 px click slop: press+release without moving = select), `graph_bounds: Rc<Cell<[f32;4]>>` written by the edges canvas prepaint. Vertex on_mouse_down starts a node drag + `cx.stop_propagation()`; area on_mouse_down starts a pan; while dragging the canvas paint registers window-wide `window.on_mouse_event` MouseMove/MouseUp listeners (drag continues outside the area). Scroll: pixel deltas pan, Lines or ⌘/Ctrl zoom. Buttons −/+/Fit/Re-layout (Re-layout always enabled).

Layout (was Fruchterman–Reingold, 2026-10): each component (Part) gets stress majorization on hop distances × ideal edge length from several starts (rings around top-3 degree nodes + scattered xorshift Rng starts), each followed by turn_and_stretch to the area aspect. Cost = crossings (CROSSING_SMALL 40 ≤16 nodes else 4) + edges through label boxes (HIT 20) + overlapping padded boxes (OVERLAP 10) + near-parallel edges at a node (ANGLE, MIN_ANGLE 20°) + stress; of(pos, vs) incremental. ≤16 nodes (ANNEAL_MAX): simulated annealing from 3 cheapest starts; larger: improve local search (swaps + moves near neighbours) under SEARCH_BUDGET. Then separate pushes boxes apart, pack shelves components, fit to area; if it doesn't fit Part::shrink(kx, ky) refines smaller (labels keep pixel size).

No-move refresh: Graph::keep(previous) always keeps existing vertices' x/y fractions and previous.area; new vertices via place(): rings (PLACE_STEP 20 px) around mean of placed neighbours (area centre if none), first ring with free box (PLACE_GAP 10 px), cheapest by link length + PLACE_CROSSING 80 × (crossings + links through labels) − room; inside area preferred. Returns false only if no old vertex survives → full lay_out(None). same_shape removed; stress majorization no longer on warm starts.

WebjetApp::loaded (ui/mod.rs): full layout only for first picture, when nothing of the old picture survives, or ONCE when graph was made for unmeasured DEFAULT_AREA and real area now known (no pinned nodes, !laying_out). start_layout runs on cx.background_executor() via layout_job/layout_seq, applies with now.keep(Some(&laid_out)); laying_out flag prevents restart on each 2 s refresh. First picture laid out synchronously.

Label boxes via vertex_box(label, infra), CHAR_W 7.8 px (measured text_xs ≈ 7.3 px/char); graph_labels_do_not_overlap UI test checks drawn width ≤ layout width.

Selection focus: Graph::focus(selected, circuit_path); nodes.rs draws two layers (edges canvas, delay labels, vertices): rest dimmed (links 0.35, labels/nodes 0.3), focus on top with solid label backgrounds.

Debug pictures: WEBJET_LAYOUT_SVG=/tmp/dir cargo test --release -p webjet-app --lib graph::tests, then qlmanage -t -s 1000 -o . file.svg (no rsvg/magick on this Mac). Timing ~200 ms release / ~2.5 s debug for 9-node network; timing assertions depend on cfg!(debug_assertions).

Tests: graph::tests a_refresh_never_moves_a_node, new_nodes_go_next_to_their_neighbors_into_free_room; ui::tests refreshes_do_not_move_the_nodes. docs/app.md Nodes section documents this.

Test filter graph:: covers both modules.

GPUI 0.2.2 test gotchas (ui::tests::every_tab_renders): simulated events hit the window's own rendered frame, not what `cx.draw(...)` painted — call `cx.simulate_resize(size(1280,820))` first, and between events redraw with `view.update(cx, |_, cx| cx.notify()); cx.run_until_parked();` rather than `cx.draw`. Overlapping vertex labels mean the grabbed node may not be the one you aimed at: read the id from `app.drag`. Calling `app.loaded(fixture())` drops the test admin account → signed out and the window renders the sign-in screen; reuse the snapshot that has the admin added.
