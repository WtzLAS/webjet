webjetup install/upgrade redesign (crates/webjetup/src, after v0.11.6):
- `install/upgrade` first calls `hand_over` (main.rs): if the target release's webjetup (downloaded + sha256-checked, or `<--from dir>/webjetup`) is newer, run it with same argv and env `WEBJETUP_HANDED_OVER=1` (loop guard), exit with its code — each release is installed by its own webjetup (`install_self`).
- `install()` only replaces programs (returns false if already installed: "already installed … setting it up again"); then always `setup_system` (retired programs, install_self, dirs, Windows ACL/PATH/Start-menu shortcut `ProgramData\Microsoft\Windows\Start Menu\Programs\Webjet.lnk`, Linux user, default config), signer::setup, remote::setup, start_after_install, `remote::note_setup`.
- Service definitions via `system::write_if_changed` (systemd unit, launchd plists, FreeBSD rc.d via `freebsd::install` → bool) and `system::windows_service` (sc.exe `qc` compared, then `create`/`config`; description/failure always reset). Restarts follow `system::Start {No, Yes, IfChanged}`.
- Hidden `webjetup setup [--start yes|no|if-changed]` = everything but programs/enroll. Remote-upgrade helper, after replacing programs + webjetup, runs new `webjetup setup --start yes` (falls back to own restart if new one lacks `setup`).
- `<spool>/setup-version` stores webjetup version that last set up the node; `apply-upgrade` (incl. `--recover`, run by systemd as ExecStopPost with the NEW binary) calls `set_up_if_outdated` → `setup(IfChanged)` once per version — fixes nodes remotely upgraded by old (≤0.11.6) helper.
- Linux unit capabilities: `system::AGENT_CAPABILITIES` = CAP_NET_ADMIN CAP_NET_BIND_SERVICE CAP_NET_RAW (NET_RAW for multicast AF_PACKET capture); CapAmb hex 0x3400.
- `layout::OPTIONAL_PROGRAMS = ["webjet-app"]`: installed when in archive, removed otherwise; `all_files()` = wanted + optional (extract/backup/remove).
- Windows install: `scripts/install.ps1` (`irm …/install.ps1 | iex`, args via `& ([scriptblock]::Create((irm …))) --enroll …`; throws instead of exit), published by scripts/release.sh with install.sh.
