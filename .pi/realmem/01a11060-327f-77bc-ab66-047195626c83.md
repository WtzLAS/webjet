- `webjetup install --signer` (crates/webjetup/src/signer.rs) does the following:
  - Linux: writes systemd unit `webjet-signer.service` (user `webjet-signer`, Group=webjet, `webjetd signer --group-access` → socket mode 0660 via `ipc::Access::Group`; Before= and WantedBy= webjetd.service; PrivateNetwork). macOS: launchd `net.webjet.signer`. Windows: service `webjet-signer` (`webjetd signer-service`, hidden subcommand; webjetd's service gets depend= on it).
  - Sets `[controller] signer_socket` in webjetd.toml with toml_edit, keeping comments.
  - Moves an existing `data_dir/signing.key` to the signer key path, and refuses if both exist and differ.
  - Stays on for later upgrades when webjetd.toml points at the signer socket (`signer::configured`). remove and nuke handle it, and `webjetup status` shows a `signer` line.
  - `signer::serve` refuses `Access::Everyone`.
- Camouflage alarm: `health::check_camouflage` runs every minute on nodes with `[listen] anytls` or on controllers. It raises the `camouflage_certificate` alarm from 30 days before expiry (critical under 7 days or once expired), using `webjet_net::anytls::not_after_ms` and `transport::camouflage_not_after`. `local status` has `camouflage_expires` (ms).
