v0.11.0 is an annotated tag on 0ec9f20, pushed with main. Its notes cover:
- broadcast/multicast + capture (§9.5.1/9.5.2);
- FreeBSD 14 / OPNsense 24.7+ x86_64;
- the desktop app;
- webjetup SOCKS proxies.

The upgrade note in ops guide "Releases without a StateVersion step": nodes need no order; upgrade every controller before the first `multicast_*` limit or `[multicast]` capture setting.

release.yml alone published the release with 38 assets, so nothing was uploaded from the Mac. The assets are:
- webjet-<tag>-<target> for 6 targets: Linux x86_64/aarch64, macOS aarch64/x86_64, Windows x86_64, FreeBSD x86_64;
- webjet-app-<tag>-<target> for the same 6 targets (Windows is a .zip holding only webjet-app.exe);
- webjetup-<tag>-<target>;
- install.sh;
- a .sha256 file for each.

Checks after publishing:
- The macOS arm64 app archive passes its sha256 and `codesign -v`, and starts on the Mac.
- The Windows app has still not been run on real Windows.
- `docker/webjetup-test.sh` was NOT run before tagging (webjetup changed: FreeBSD services, SOCKS).
- `docker/release-test.sh v0.11.0` has not been run yet.
