Releases: tag `vX.Y.Z` (annotated, notes in the message = release description), version in workspace Cargo.toml must match. `scripts/release.sh vX.Y.Z [--publish]` (run on macOS with Docker, tag checked out) builds macOS aarch64/x86_64 natively, Linux aarch64/x86_64 via `docker/release.Dockerfile` (Debian 11 → glibc 2.31+), and Windows x86_64-pc-windows-msvc via `cargo xwin`. Packages `dist/<tag>/webjet-<tag>-<target>.tar.gz` + `.sha256` (4 binaries at top level: webjetd, webjetctl, webjet-root, webjet-signer); Windows zip `webjet-<tag>-x86_64-pc-windows-msvc.zip` for upgrade.ps1 holds the 4 .exe files + wintun.dll 0.14.1 (amd64, sha256 of wintun-0.14.1.zip 07c25618…f51 pinned in release.sh) + wintun-LICENSE.txt (Wintun license allows redistribution alongside software using it via its API). Pushes the tag, creates the Forgejo release via API and uploads assets. Needs `WEBJET_FORGEJO_TOKEN` (here `$VP309_FORGEJO_TOKEN` works). Repo webj8/webjet on forgejo.wolf109909.top is public; install URL for upgrade.sh: `WEBJET_RELEASE_URL=https://forgejo.wolf109909.top/webj8/webjet/releases/download`. Verify with `WEBJET_TEST_DNS=1.1.1.1 WEBJET_RELEASE_URL=… docker/release-test.sh vX.Y.Z` (Debian 11, Ubuntu 20.04, Debian 12 × amd64/arm64). Debian 11 quirks: archived security mirror 404s (drop security lines for test containers; on amd64 libclang pulls libc6-i386 etc. → empty stub debs), Debian's cmake 3.18 < BoringSSL's 3.22 → Kitware cmake 3.31. Docker's default resolver on this Mac can't resolve forgejo.wolf109909.top (use --dns 1.1.1.1). Windows cross-build quirks: cargo-xwin needs Homebrew `llvm` AND `lld` on PATH (`/opt/homebrew/opt/lld/bin:/opt/homebrew/opt/llvm/bin`); without Homebrew lld-link, cargo-xwin symlinks `~/Library/Caches/cargo-xwin/lld-link` → rustup's `rust-lld`, which can't run standalone (dyld: missing libLLVM.dylib), so CMake deps (boring-sys, aws-lc-sys) fail "C compiler is not able to compile a simple test program". Fix: delete that symlink and `target/x86_64-pc-windows-msvc/release/build/{boring-sys,aws-lc-sys}-*` (CMake caches CMAKE_LINKER). v0.1.0 = commit 9bd8ae9, published 2026-10-03, Forgejo release id 12; Windows zip added to that release on 2026-10-04, checked under Wine (all tools report 0.1.0), not on real Windows.
