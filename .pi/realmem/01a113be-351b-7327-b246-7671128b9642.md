`crates/webjet-tools/src/lib.rs` seal/unseal (commit cd6bc3a):
- `WJE1` = magic|salt16|nonce12|ct. It decodes with the pinned `KDF_V1` (m=19456 KiB, t=2, p=1 — argon2 0.5/0.6 `Argon2::default()`). A test checks equality with `Argon2::default()`.
- `WJE2` = magic|m_cost|t_cost|p_cost (u32 LE)|salt|nonce|ct. `seal` writes `KDF_NEW` (64 MiB, t=3, p=1).
- `KdfParams::derive` refuses m outside 8 MiB–1 GiB, t outside 1–16, p outside 1–8, so a hostile file can't force a huge allocation.
- Root `Cargo.toml` sets `[profile.dev.package.argon2]`/`blake2` `opt-level = 3`, so debug tests stay fast.

Secrets written to user-chosen paths (`--out`, `--key-out`, root backup) use `webjet_tools::write_secret`: atomic, 0600, parent dir untouched (created private only if it is new). `write_private` (webjetd::state) restricts the parent dir to 0700, so it is only for directories webjet owns (key dir, data dir).

Passphrases: `prompt::passphrase`/`new_passphrase` return `Passphrase = Zeroizing<String>`. `new_passphrase` refuses a set-but-empty env var. `root restore` refuses an existing key dir without `--force`. webjet-app's `Field` keeps its text in `Zeroizing<String>`, and the passphrase field is cleared after every sign-in attempt.
