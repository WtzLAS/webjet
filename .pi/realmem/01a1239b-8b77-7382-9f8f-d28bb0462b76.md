After `cargo update` (2026-10) the only crate behind the newest version is generic-array 0.14.7, which crypto-common 0.1.7 pins with `=0.14.7` (through gpui → oo7 → cipher), so it can't move. Changes made: webjetup `zip = "9"` (was 8; no code changes needed, webjetup tests pass). In vendor/gpui/Cargo.toml and vendor/gpui_media/Cargo.toml the exact pins were relaxed, each with a `Webjet:` comment: `core-foundation "=0.10.0"` → `"0.10"` (netconfig-rs 0.1.6 via tun-rs/webjetd needs 0.10.1; this also pulled in netlink-packet-route 0.25), and `taffy "=0.9.0"` → `"0.9"`. `cocoa =0.26.0` and `cocoa-foundation =0.2.0` deliberately stay pinned: cocoa 0.26.1 deprecates its whole API (objc2 migration), which floods the macOS gpui build with hundreds of deprecation warnings. Redo these relaxations when updating the vendored gpui (they are listed in vendor/README.md). Direct workspace deps have no newer major versions besides that.
