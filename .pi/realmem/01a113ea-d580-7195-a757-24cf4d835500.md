Phase 4 (2026-10, after 080fbf9) DoS/unbounded-growth limits:
- webjet-net kcp/mod.rs: `MAX_DATAGRAM` (sealed OPEN + MAX_SHARD + pad) dropped before decrypt; `MAX_HANDSHAKING`=256 accepted sessions in TLS (RAII `HandshakeSlot` in `KcpConn.handshake`, held by `hop::accept_kcp`), `MAX_SESSIONS`=8192; session map entries carry an id, `forget_session` removes only its own. RAW_ACK goes through `Kcp::input_control` (PUSH refused); `input` refuses segments > MSS (`Error::Oversize`); per-segment RTO backoff capped at RTO_MAX.
- gate.rs `ReplayCache`: full cache of live nonces refuses new ones (fails closed) instead of evicting.
- hop.rs `encode_record` returns `Option` (None over MAX_RECORD); `write_record` errors; webjetd `node::ctl` returns Option.
- webjetd node.rs writer: `CONTROL_QUEUE_MAX` 32 MiB of queued control bytes (HopQueue::control_bytes) closes the hop; writes under `WRITE_DEADLINE` (=HOP_DEAD).
- gossip.rs: `SYNC_REQUESTS_PER_SEC`=1000 per hop for GetOffline/GetBuckets/GetBucketIndex/GetLeaves; lookup_rate/sync_rate pruned every 30 s with head_rx.
- circuit.rs Table: setup rate checked before the nonce is recorded; nonces in a time-ordered VecDeque (NONCE_WINDOW 300 s); `transit`/`per_source` counters maintained via `insert_entry`/`remove_entry` (all entry inserts must go through `insert_entry`).
- control/mod.rs: IDLE_TIMEOUT 60 s per request read, WRITE_TIMEOUT 30 s.
- Node `rpc_tasks` (rpc::MAX_INBOUND 256) and `dns_tasks` (dns::MAX_INFLIGHT 512) semaphores; dns forward accepts only replies from (server,53) with the query id; dataplane refresh prunes gw_choice to published prefixes.
