Deadlocks were the most common Webjet agent bug (found by running real traffic, diagnosed with macOS `sample <pid>`). Rules: never call a helper that takes a lock while holding a lock it may take — clone, drop guard, then call (`Node::records`, `Node::hops`, `Node::circuits`, store, e2e session `inner`; e.g. `transport::priority` locks records, so `endpoint_addrs` must clone the record first; `e2e::Sessions::in_progress` iterates all sessions so compute it before locking one). `Node::store` is a `StoreLock` wrapper whose `read()` is `read_recursive()` because nested reads happened everywhere and a queued writer deadlocked a fair RwLock. Never hold parking_lot guards across `.await`. Controller `apply_committed` and snapshot install share `apply_lock`.
