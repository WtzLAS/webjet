Webjet (/Users/laser_rks/Projects/webjet) is a Rust overlay VPN implementing `docs/webjet-architecture.md` (design; § numbers are referenced in code comments). Edition 2024, rust-version 1.88.

Crates: `webjet-proto` (planus FlatBuffers), `webjet-core` (pure deterministic logic: crypto envelopes, sparse Merkle tree, trust store, controller state machine, policy, routing, frames, packet/NAT, conntrack, FQ-CoDel queue), `webjet-net` (PSK gate, raw-public-key TLS 1.3 with X25519MLKEM768 only, KCP+FEC, AnyTLS via BoringSSL feature `anytls`), `webjetd` (agent, plus the controller role with its own Raft), `webjet-tools` (`webjetctl`, incl. `init`/`enroll` and the offline `webjetctl root`; since 0.3.0 there is no `webjet-root`/`webjet-signer` binary, the signer is `webjetd signer`), `webjetup` (installation manager), `webjet-app` (GPUI desktop app).

Docs for humans: `docs/webjet-operations-guide.md` (runbooks 1–11, written against the real CLIs and tested by `docker/runbook-test.sh`), `docs/configuration.md` (webjetd.toml), `docs/docker.md`, `docs/app.md`, `docs/development.md` (build, tests, CI, releases, conventions, pitfalls).
