Webjet (/Users/laser_rks/Projects/webjet) is a Rust overlay VPN implementing `docs/webjet-architecture.md` (design, § numbers referenced in code comments) and `docs/webjet-operations-guide.md` (runbooks 1–11). Crates: `webjet-proto` (planus FlatBuffers), `webjet-core` (pure deterministic logic: crypto envelopes, sparse Merkle tree, trust store, controller state machine, policy, routing, frames, packet/NAT, conntrack, FQ-CoDel queue), `webjet-net` (PSK gate, raw-public-key TLS 1.3 with X25519MLKEM768 only, KCP+FEC, AnyTLS via BoringSSL feature `anytls`), `webjetd` (agent + controller role with own Raft), `webjet-tools` (`webjetctl`, `webjet-root`, `webjet-signer`). Edition 2024, rust-version 1.88. Docs for humans: docs/configuration.md (webjetd.toml), docs/docker.md, docs/development.md (build/test/conventions/pitfalls).
