FreeBSD/OPNsense prep (2026-10, user wants to deploy to OPNsense later; agent runs as root), cfg `target_os = "freebsd"`:
- tun (crates/webjetd/src/dataplane.rs `start`): tun-rs on FreeBSD only accepts `tunN` names (opens /dev/tunN). For other configured names (default `webjet0`) webjetd builds without a name then calls `dev.set_name` (SIOCSIFNAME). Before building it runs `platform::destroy_stale_tun(name)`: FreeBSD tun interfaces outlive a killed process, so a leftover listed by `ifconfig -g tun` whose `ifconfig <name>` output has no "Opened by PID" gets `ifconfig <name> destroy`. `platform::is_tun_unit` detects `tunN`.
- routes (platform.rs `route_cmd`): same BSD `route -q -n add -inet[6] NET -interface DEV` as macOS. `add_route` falls back to `route change` on macOS/FreeBSD when the route already exists (tun-rs's associate_route already adds the pool prefix route) — `bsd_change`.
- split DNS: not configured on FreeBSD; warns once (OPNsense Unbound query forwarding by hand). Gateway NAT and reverse proxy stay Linux only.
- multicast groups: macOS `getifmaddrs` FFI (`groups_os`) shared with FreeBSD (same struct ifmaddrs layout).
- capture (capture.rs): macOS BPF module shared (`mod os` cfg any(macos, freebsd)). ioctl numbers via `ioc()` (_IOC) with const asserts against 64-bit values. FreeBSD opens cloning `/dev/bpf` and sets `BIOCSDIRECTION` (=119, `_IOW('B',119,u_int)`; 118 is GDIRECTION) to BPF_D_OUT. `bpf_records(buf, &BpfHdr)`: macOS caplen@8/hdrlen@16/align 4; FreeBSD 64-bit caplen@16/hdrlen@24/align 8 (libc::bpf_hdr offsets, const-asserted). `NOT_CAPTURED_IFS` skips utun/tun/tap/ipsec/enc/ovpn/wg/ppp/gif/gre/stf/awdl/llw/pflog/pfsync. nat.rs TUNNEL_PREFIXES gained `ovpn`, `enc`, `gre`.
- Services (webjetup alone generates FreeBSD service files; no hand-installed copies in repo): `crates/webjetup/src/freebsd.rs` `RcService::script()` generates rc.d scripts run by `/usr/sbin/daemon -P /var/run/<name>.pid -R <delay> -S -T <tag> -t <tag> <prog> <args>` (daemon passes SIGTERM to child at stop, restarts after exit, sends output to syslog). Two services: `webjetd` (`/usr/local/etc/rc.d/webjetd`, REQUIRE: NETWORKING syslogd, KEYWORD: shutdown, `webjetd_config` var, required_files) and `webjet_signer` (underscore: rc.subr names become shell variables; BEFORE: webjetd; tag `webjet-signer`). `install()` writes the script (0755) and runs `sysrc -f /etc/rc.conf.d/<name> <name>_enable=YES`. OPNsense starts every daemon enabled in /etc/rc.conf.d at boot ("autorun"). Stop = `service X onestop`; `state()` uses `service X onestatus`/`enabled`. Remote upgrade helper: cron file `/usr/local/etc/cron.d/webjet-upgrade` runs `webjetup apply-upgrade` every minute as root, logging to /var/log/webjet-upgrade.log. `webjetup nuke` also runs `ifconfig webjet0 destroy`.
- Paths: config `/usr/local/etc/webjet/webjetd.toml` (webjetd `default_config_path`), state `/var/db/webjet`, signer key `/var/db/webjet-signer/signing.key`, upgrade spool `/var/db/webjet-upgrade` (webjet-release `default_spool_dir`), runtime `/var/run/webjet`.
- `webjet_release::TARGETS` now has 6 entries incl. `x86_64-unknown-freebsd`, `target()` maps it; rollout's `pin_release` lists missing targets as a note. release.sh and CI don't build FreeBSD yet. `scripts/install.sh` accepts `FreeBSD`, uses `sha256 -q` fallback.
- Tests: rc.d scripts checked with `sh -n`. Docs: README platform table, architecture §19.1 table (FreeBSD column + remote upgrade helper row) and bullet "FreeBSD (OPNsense) is being prepared", §9.5.1/§9.5.2, configuration.md (path, `[tun] name` row, restart via `service webjetd restart`, OPNsense "memory file systems for /var" warning), ops guide signer line.
