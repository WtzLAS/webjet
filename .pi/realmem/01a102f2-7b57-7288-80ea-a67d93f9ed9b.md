All CLI passphrase input goes through `crates/webjet-tools/src/prompt.rs` (re-exported as `webjet_tools::{passphrase, new_passphrase}`): env var first (WEBJET_ROOT_PASSPHRASE, WEBJET_BACKUP_PASSPHRASE, WEBJET_ACCOUNT_PASSPHRASE), else on a terminal crossterm raw mode echoing `*` per character (Backspace/Ctrl-H, Ctrl-U clears, Ctrl-C/Ctrl-D/Esc cancel → "cancelled", key releases ignored for Windows); without a TTY a plain stdin line (scripts). `new_passphrase` (webjet-root init/backup/restore, webjetctl account keygen) asks twice, 3 attempts. webjet-app's secret Field shows `*`. Tested via a Python pty driver (typed secrets never appear in output).
