Since P4 refactor (after 0.7.1): `crates/webjetd/src/control.rs` became `control/mod.rs` (serve, read_request, handle, COMMANDS access table, submit_op/submit_signed/forward_offline, client::call) + `control/request.rs` (`pub enum Request`, `#[serde(tag = "cmd", rename_all = "snake_case")]`; binary args base64 via `with = "base64"`, node ids hex `Option<Bytes32>` via `hex_id`; `to_json()`, `name()`) + `control/commands.rs` (`run(n, Request)` dispatch and one fn per command; `status` re-exported as `control::status`).
- `handle(n, Value)`: checks `cmd` against COMMANDS first (error text "unknown command X" — webjet-app matches on it to detect old agents), then `serde_json::from_value::<Request>` ("bad arguments for X"), then `commands::run`.
- `client::call(path, &Request)` is used by webjetctl (`call(cli, Request::…)`), webjet-app `Client::call/get(Request)`, and agent.rs enroll (`RedeemSelf`).
- Wire form is exactly the old hand-built JSON (test `the_wire_form_is_the_old_hand_built_json`), so mixed versions interoperate; new args must be optional.
- Tests: COMMANDS must equal the enum's variant names (parsed from request.rs source via include_str!, converted to snake_case); fuzz target `control_request` (round trip).
- Adding a command: variant in Request + COMMANDS entry (+ state-changing test list if not Read) + arm in commands::run.
