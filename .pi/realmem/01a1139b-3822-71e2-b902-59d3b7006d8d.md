Phase 2 fixes (commits cf95d4f..3dfac66):
- `packet::Parsed.frag_id` (IPv4 Identification / IPv6 frag header id; 0 when whole). `Conntrack` keeps `frags: HashMap<FragKey{peer,proto,src,dst,id}, Instant>` (FRAG_TIMEOUT 30 s, FRAG_CAP 16384): set when a First fragment is inserted or Tracked; Later fragments matching are Tracked; otherwise UDP/other Later → New, TCP/ICMP → Invalid; `initial_state` returns None for Later (never inserted). Cleared on drop_peer, on reevaluate dropping flows, pruned in expire.
- webjetd node.rs `DialSlot` RAII guard for `Node::dialing` (dial_node runs under 12 s timeout); `register_hop` duplicate check + insert under one `hops` lock (loops after PeerLost replacement).
- dataplane.rs: `Routes {installed, failing}`; `platform::add_route/del_route` return bool; failed adds retried each refresh. `Dataplane.system: Mutex<bool>` held by refresh and shutdown for their whole run; refresh no-ops after shutdown.
- webjet-net fec.rs Decoder keeps groups by `newest.wrapping_sub(g) < WINDOW(64)`.
- webjet-core proxy.rs `Table::forget` only removes by_client/by_flow mapping still pointing at the forgotten key.
- webjet-tools `config::edit_network` (set/unset at network scope) keeps emptied sections as empty so `over()` doesn't merge old values back.
- webjetctl: enrollment ticket built before submit (enroll/rekey); `expires_at()` checked; account rekey uses the account's real name.
