**Post-0.8.0 problem**: under load, e2e probes and keepalives queued behind the circuit's own data (HopQueue → KCP duplex → KCP send queue/pacer, or TCP send buffer), so their RTT/loss shot up and sessions switched to idle circuits.

**Raw transport measurement (meter.rs)**: `Meter::{Kcp, Tcp}`, `Sample { rtt_ms: Option<(mean, min)>, loss, packets }`. `MeteredTcp` wraps TcpStream for TCP+TLS/AnyTLS (dial+accept); `TcpMeter` reads `TCP_INFO` (Linux), `TCP_CONNECTION_INFO` (macOS) or `SIO_TCP_INFO` (Windows). macOS uses its own 112-byte `TcpConnectionInfo` (libc's struct splits the TFO bitfield into 15 u32s → wrong offsets, sent=0). KCP: `K_RAW_ACK=5` (`held_us[4]||KCP ACKs`) sent at once outside FEC/pacer, only to peers whose STATS carry flag byte 1 (STATS 14 bytes; older peers 13); receiver subtracts `held`. `RawRtt` measures socket→ACK (after pacer), Karn's rule, per-datagram arrival time `Arrived=(Instant,Vec<u8>)`; loss = FEC shard-group loss both ways; BBR min_rtt uses raw RTT; DUPLEX 512→64 KB; user data only while `paced.len() < bbr.window()`. `LinkStats::on_raw(rtt, loss, packets, now_us, now_ms)` (routing.rs): after first raw RTT (`raw=true`) keepalive acks/losses no longer move srtt/loss; `outcomes` are (lost,total) pairs; `LinkHistory::observe_raw`. node.rs keepalive reads `hop.meter.take()` every 2 s → `on_raw`; CoDel `tune` uses KCP bw estimate.

**v0.10.2 probe-traffic redesign** (commits 3478887 probe cut, f2a5cce memories, 35017d7 version bump + install refs + ops guide 3.3 note "0.10.2 needs no order"; annotated tag v0.10.2 at 35017d7 pushed with main; docs refer to "nodes before 0.10.2"; architecture §11.2/§11.4/§9.4.3/§17.6 updated, uncommitted at the time):
- **Keepalives (node.rs, 1 s tick)**: only the dialer (hop.outbound) sends, flag KA_ONE_SIDED; interval KEEPALIVE 2 s for first 30 s / lossy >1% / last unanswered, else KEEPALIVE_SLOW 5 s. Accepting end answers, sets Hop.peer_keeps; sends own only if none by 2×KEEPALIVE into hop (old peer) or none for 12 s. One-sided keepalive carries observed_addr every 12th; receiver derives clock offset from wall_ms + srtt/2; KeepaliveAck.digest carries answering edge node's digest. Meter read every 2 s. `Node::test_hop_dir(peer, transport, outbound)`.
- **Probes (paths.rs on_probe/on_probe_ack/send_probe/probe_now, circuit.rs Live.{next_probe,passive,last_reply})**: PROBE_FAST/PRIMARY/BACKUP 1/5/15 s, PROBE_WARMUP 3, PASSIVE_SILENCE 20 s, route_tag(). Source-only slower compact e2e probes `Probe{route_tag, sent_at_us(=seq), echo_us, held_us}`; answer `{route_tag, sent_at_us, reply_at_us}`; destination goes passive on new-format probe, measures RTT via LinkStats::on_rtt. Old-format probes (route_id set) answered as plain echo. Probe timing uses tokio Instant (paused-time tests). e2e on_frame: PROBE/PROBE_ACK no longer update last_used; probes no longer count as session use.
- **KCP (kcp/mod.rs)**: K_SHARD_ACK=6 (`held[4]||acks_len[2]||acks||shard`), STATS flag STATS_SHARD_ACK=2; lone small ack (≤2×24 B) held ≤ ACK_HOLD 10 ms to ride a shard (sparse STATS). STATS every 1 s while loss in last STATS_QUIET 10 s, else every 10 s. Small-packet padding 0–31 B (gate.rs).
- **Schema appended fields**: Probe.{route_tag,reply_at_us,echo_us,held_us}, Keepalive.{flags,observed_addr}, KeepaliveAck.digest.
- **Tests**: `crates/webjetd/src/probe_traffic.rs` (#[cfg(test)] mod in lib.rs): keepalives_per_hop (real node::keepalive + node::handle_control, pub(crate), on test_hops with start_paused), probe_record_sizes, ignored `wire::wire_cost` (`cargo test -p webjetd --lib probe_traffic -- --ignored --nocapture`, WEBJET_PROBE_SECS); `e2e::handshake_tests::probe_traffic_on_an_idle_circuit` runs paths::run both ends; webjetd dev-dep tokio test-util; documented docs/development.md "Probe traffic".
- **Measured overhead** (wire::wire_cost, full agents, loopback): idle KCP hop 2.5 dgram/s ≈480 B/s each way → 0.4–0.7 dgram/s ≈130–150 B/s; TCP 165 → 85 B/s. Per in-use idle circuit e2e probe records 208 B/s per end → ~25 B/s.

**Circuit cost (paths.rs `path_cost`, circuit.rs `LocalCircuit::cost`)**: live first hop + `Graph::link` (relay links/attachments) along `relays_from_me()`; no load penalty; full relay ×4. Probe cost only while links are unknown; cost infinite after a probe unanswered 3 s with nothing received. Probes skipped when `busy()`: ≥3 session frames each way per 1 s interval (`Live.tx/rx` in e2e send/on_frame); idle circuits still probed every second. `sessions` JSON has `cost` per circuit.

**Load test**: `docker/load-test.sh` (subnets 172.33.x; each data node enrolls via the controller IP on its own network; image needs `-e WEBJET_CONFIG=/etc/webjet/webjetd.toml`). Result: 0 switches during 40 s bulk transfer, 0 probes on the loaded circuit, 37 on the idle one. Docs: architecture §11.2, §11.4, §9.4.3, §11.8.3, §17.2, §17.5; development.md.

**Release mechanics**: macOS release assets built by a bg script that waits for the Forgejo actions API (`/api/v1/repos/webj8/webjet/actions/tasks`, no auth) to show the tag's release job done, then runs `WEBJET_FORGEJO_TOKEN=$VP309_FORGEJO_TOKEN scripts/release.sh v0.10.2 --publish --targets "aarch64-apple-darwin x86_64-apple-darwin"`.
