`crates/webjet-core/src/statemachine.rs` must be deterministic (§15.5): no wall clock (use entry `timestamp`), no randomness (use entry `random`, chosen by the leader in `prepare`), ordered maps only. Leader prepares entries incl. resulting leaf bytes; followers recompute and halt on divergence. Genesis creates PSK epoch 0. FlatBuffers schema changes (`webjet-proto/schema/{webjet,wire}.fbs`): only append table fields / union variants (old nodes must decode new messages, §15.7), then run `crates/webjet-proto/regen.sh` and commit generated.rs. Example appended fields: `RelayLoad.queue_pct`, `MetricReport.load`.
