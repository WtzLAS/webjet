Webjet (Rust VPN, docs/webjet-architecture.md) uses planus 1.3 for FlatBuffers; planus does NOT support struct arrays (`[ubyte:32]`), so Key32/Sig64/Id16/Cidr are structs of little-endian u64 words (b0..b3) with the same byte layout. Schemas: `crates/webjet-proto/schema/{webjet.fbs,wire.fbs}`; regenerate with `crates/webjet-proto/regen.sh` (needs `cargo install planus-cli --version 1.3.0`), output `src/generated.rs` is checked in. Schema changes: only append table fields / union variants so old nodes decode new messages (§15.7), then run regen and commit generated.rs. Example appended fields: `RelayLoad.queue_pct`, `MetricReport.load`. Generated owned types derive serde; decode via `XRef::read_as_root(bytes)` + `X::try_from(ref)`, encode via `planus::Builder::finish(&obj, None)`. `crates/webjet-core/src/statemachine.rs` must be deterministic (§15.5): no wall clock (use entry `timestamp`), no randomness (use entry `random`, chosen by the leader in `prepare`), ordered maps only. Leader prepares entries incl. resulting leaf bytes; followers recompute and halt on divergence. Genesis creates PSK epoch 0.
