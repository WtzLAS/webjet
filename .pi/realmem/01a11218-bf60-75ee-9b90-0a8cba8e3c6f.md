Seed addresses (`transport:host:port`, parsed by `webjet_tools::parse_seed_addr` in crates/webjet-tools/src/lib.rs) accept IPv4, `[IPv6]` or a DNS name (lowercased, trailing dot stripped, `webjet_core::validate::valid_dns_name`). The controller's `check_seeds` (statemachine.rs) always accepted DNS names, so there are no wire or compatibility changes. Each node resolves seed names when it dials them (`agent.rs` `seed_addrs` → `resolve` → `tokio::net::lookup_host`).
webjetd.toml `[[public]] addr` is `config::HostPort` (serde try_from String: `ip:port`, `[v6]:port` or `name:port`). Names are resolved by the oneshot task "public-names" (`transport::resolve_public`): at start and then every 5 min, results stored in `Node::public_resolved`. When the addresses change it calls `publish_endpoint(force)`. `transport::my_addrs` advertises every resolved IP as AddrKind::Public.
