`crates/webjet-app/src/graph.rs` `layout(items: &[Item], edges, area_px)` replaced the old Fruchterman–Reingold layout (2026-10). Design:
- Lays out each connected component on its own (`Part`). Uses stress majorization on hop distances × ideal edge length from several starts (rings around the top-3 degree nodes plus scattered starts from a deterministic xorshift `Rng`), each followed by `turn_and_stretch` to fit the area's aspect ratio.
- `Cost` adds up crossings (`crossing` = CROSSING_SMALL 40 for ≤16 nodes, else 4), edges through another node's label box (HIT 20), overlapping padded boxes (OVERLAP 10), near-parallel edges at a node (ANGLE, MIN_ANGLE 20°) and stress. `of(pos, vs)` is incremental.
- Components with ≤16 nodes (ANNEAL_MAX) are simulated-annealed from the 3 cheapest starts. Larger ones get the `improve` local search (swaps + moves near neighbours) under SEARCH_BUDGET.
- Then `separate` pushes boxes apart, `pack` arranges components on shelves, and the picture is fit to the area. If it doesn't fit, `Part::shrink(kx, ky)` refines at the smaller scale, because labels keep their pixel size.
- Warm start: `Item.start` holds the old positions. `Part::warm` rescales the wanted distances to the old picture's scale and runs ONLY `improve` (stress majorization there undid the old picture). It is used unless `looks` (cost without stress) > fresh × 1.5 + 40.
- Label box sizes come from `vertex_box(label, infra)` with CHAR_W 7.8 px. Measured text_xs is about 7.3 px/char; the `graph_labels_do_not_overlap` UI test checks that the drawn width is ≤ the layout's width.
- App: `Graph::shape` + `keep(previous)` (same shape and area within 10% → keep positions) + `lay_out`. `WebjetApp::start_layout` runs the layout on `cx.background_executor()`, using `layout_job`/`layout_seq`; the first picture is laid out synchronously.
- Selection focus: `Graph::focus(selected, circuit_path)` returns the vertices and edges in focus. nodes.rs draws two layers (edges canvas, delay labels, vertices): first the rest, dimmed (links 0.35, labels/nodes 0.3), then what is in focus, with solid label backgrounds.
- Debug pictures: `WEBJET_LAYOUT_SVG=/tmp/dir cargo test --release -p webjet-app --lib graph::tests`, then `qlmanage -t -s 1000 -o . file.svg` to get a PNG you can view (no rsvg/magick on this Mac).
- Timing: the reported 9-node network takes ~200 ms in release and ~2.5 s in debug, so the timing assertions in tests depend on `cfg!(debug_assertions)`.
