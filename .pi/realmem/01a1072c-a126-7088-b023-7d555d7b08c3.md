Since node roles were unified (`--roles data,relay,control`), `docker/entrypoint.sh` writes `[controller] enabled = false` only when `WEBJET_CONTROLLER` is set to a false value. Otherwise it writes nothing, and the controller role starts when the node has the control role, or on the genesis node (`WEBJET_GENESIS`). `-e WEBJET_CONTROLLER=true` was removed from docs/docker.md, docker/compose.example.yaml, docker/deploy-test.sh and docker/webjetup-test.sh. In docker/node.sh (e2e) the second argument is now the gateway prefix (the controller flag is gone).
