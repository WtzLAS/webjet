`crates/webjet-app` is a GPUI (crates.io gpui 0.2.2) desktop app. It talks to the local webjetd control socket (like webjetctl) and signs ops with an account key via `webjet_tools::Account::unlock`/`sign` (moved from webjetctl into the webjet-tools lib). Permissions: admin = everything; normal account = read-only except rename/revoke of nodes it owns (`model::Session::may`); controllers enforce the same. `model.rs` + `client.rs` are GUI-free and unit-tested; `tests/live.rs` runs against `scripts/local-net.sh 2` (skips otherwise). Control channel `nodes` now includes `owner_id`. GPUI needs feature `runtime_shaders` on machines with only Command Line Tools (no `xcrun metal`). GPUI closures in `Application::run` must be 'static; app uses its own tokio runtime for IO and `cx.spawn` to update. Linux clippy in plain rust image must `--exclude webjet-app` (GPUI system deps). Screenshots of the window weren't possible here (no screen-capture/accessibility permission), so the GUI was only verified by launching and via the headless tests.

webjet-app UI (crates/webjet-app/src/ui/) is one file per tab: dashboard.rs, connections.rs, nodes.rs, metrics.rs, accounts.rs; shared pieces + WebjetApp state in ui/mod.rs. GUI-free logic: model.rs (Snapshot incl. sessions/conntrack/topology/metrics as Result<_, String> so old agents still work; health(), Traffic, Summary), graph.rs (Graph::from_snapshot, deterministic Fruchterman–Reingold layout), openmetrics.rs (parser).
Data comes from webjetd control commands `sessions` (circuit::summary), `conntrack` (dataplane::flows, each flow with the circuit its peer's e2e session sends on), `topology` (gossip::topology: LSA relay links, attachments, own hops), `metrics` ({"all":bool} on controllers). webjetctl has `local sessions|conntrack|topology`.
Headless render test: `ui::tests::every_tab_renders` uses gpui `test-support` (dev-dependency) + TestAppContext/add_window_view/cx.draw, fed from crates/webjet-app/tests/fixtures/node-02.json (agent answers captured from `scripts/local-net.sh 4`, node-02 control socket; regenerate when the agent's JSON changes). screencapture doesn't work in this environment (no screen-recording permission), so visual checks aren't possible; rely on the headless test.
GPUI gotcha: closures like `let opt = |r| ...` can't be generic; use nested `fn opt<T>(..)`.
