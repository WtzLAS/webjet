Webjet (Rust VPN implementing docs/webjet-architecture.md) uses planus 1.3 for FlatBuffers. planus does NOT support struct arrays (`[ubyte:32]`), so Key32/Sig64/Id16/Cidr are structs of little-endian u64 words (b0..b3), same byte layout. Schemas: crates/webjet-proto/schema/{webjet.fbs,wire.fbs}; regenerate bindings with `crates/webjet-proto/regen.sh` (needs `cargo install planus-cli --version 1.3.0`), output src/generated.rs (checked in). Generated owned types derive serde; decode via `XRef::read_as_root(bytes)` + `X::try_from(ref)`, encode via `planus::Builder::finish(&obj, None)`.
