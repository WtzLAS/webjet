v0.10.1 is an annotated tag on 02a3a7f (fix commit 31e4b2e), pushed to main on Forgejo. `webjetctl network node upgrade` (crates/webjet-tools/src/bin/webjetctl/rollout.rs) now skips a node when the UpgradeStatus call fails (offline / pre-0.9.0), when it has no helper, when `[upgrade] remote = false`, or when the Upgrade request is refused. Each skip prints "<node>: skipped: <reason>" to stderr, and the summary lists the skipped nodes; `--json` output has a `"skipped"` array. A node that accepted the request but then fails, rolls back or times out still stops the rollout. `docker/webjetup-test.sh` step 6d checks the skip (exit 0, "laptop: skipped: …turned off", "1 node(s) skipped") and passed before tagging. Ops guide 3.3 and the "Releases without a StateVersion step" note were updated (0.10.1: no order needed).

Release automation used on the Mac: `.pi/tmp/release-mac.sh` polls `GET /api/v1/repos/webj8/webjet/actions/tasks` (fields `workflow_runs[].name/status/head_branch`) until the tag's `release` job succeeds. It then runs `WEBJET_FORGEJO_TOKEN=$VP309_FORGEJO_TOKEN scripts/release.sh <tag> --publish --targets "aarch64-apple-darwin x86_64-apple-darwin"`.
