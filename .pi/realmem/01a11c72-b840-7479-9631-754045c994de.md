**Cargo mirror (since v0.11.4, re-tagged c2eda16 after fix f505ede).** Every job in .forgejo/workflows/ci.yml and release.yml runs `scripts/cargo-mirror.sh` right after checkout. It writes a `[source.crates-io] replace-with = "mirror"` + `[source.mirror] registry` (+ `[registries.mirror] index`) config (as on https://help.mirrors.cernet.edu.cn/crates.io-index/) between `# --- cargo-mirror.sh begin/end` markers in `$CARGO_HOME/config.toml` (builder image: /usr/local/cargo, no config before; rerun replaces the block; refuses a foreign crates-io replacement). It then tries `cargo fetch --locked` per source and keeps the first that succeeds: `sparse+https://mirrors.tuna.tsinghua.edu.cn/crates.io-index/` → `sparse+https://mirrors.ustc.edu.cn/crates.io-index/` → plain crates.io (no replacement). Extra args = additional URLs tried in order. Rationale: USTC answered CI with HTTP 429 Rate limited via proxy 192.168.31.199 (v0.11.4 first tag failed); 2026-10-10 findings on runner box 10.4.0.9: MirrorZ endpoint mirrors.cernet.edu.cn times out (direct & via proxy; from the Mac it 302s to mirror.nju.edu.cn) and MirrorZ members' sparse indexes (NJU, SJTUG, TUNA, BFSU) lag hours behind crates.io (missing tokio-util 0.7.20/zstd 0.14.1 right after cargo update) — only USTC was live then. Cargo.lock still says crates.io (checksums verified), so --locked and deny.toml `allow-registry = crates.io` keep working (deny ok in fallback tests: lock behind TUNA → USTC in 41 s; older lock → TUNA in 8 s). fuzz.yml does not use it. Runner NO_PROXY (/root/docker/forgejo-runner/data/runner-config.yml envs + docker-compose.yml dind env, backups *.bak-20261010003333) now includes mirrors.tuna.tsinghua.edu.cn, mirrors.ustc.edu.cn, mirrors.cernet.edu.cn; runner container restarted. v0.11.4 tag was deleted and re-created on c2eda16.
