CI image `forgejo.wolf109909.top/webj8-internal/webjet-builder:5` (webjet-builder commit db95429, digest sha256:61b2face…) is used by webjet's ci.yml/release.yml/fuzz.yml since webjet commit 7d35ad5. Repo `ssh://git@forgejo.wolf109909.top:2222/webj8-internal/webjet-builder.git` (org private; repo `private` flag false but anon gets 404), local checkout `~/Projects/webjet-builder` (Dockerfile, .dockerignore, build.sh, scripts/macos-sdk.sh, scripts/freebsd-sysroot.sh, README). Image exists to hold Apple's macOS SDK (no redistribution); Forgejo packages follow owner visibility, so never push under public `webj8`. Version 5 adds: libxkbcommon(-x11)/libxcb dev packages for amd64 plus arm64 .debs unpacked into /usr/aarch64-linux-gnu (multiarch apt install fails: libc6:arm64 lags amd64 security update), zstd, and a FreeBSD sysroot with those libs from pkg.freebsd.org `FreeBSD:14:amd64/release_4` (pinned in scripts/freebsd-sysroot.sh `PKGS`). CI now runs clippy/test on webjet-app for Linux and FreeBSD; release.sh ships `webjet-app-<tag>-<target>.tar.gz` for Linux x86_64/arm64 and FreeBSD. Windows/macOS app still blocked: gpui 0.2.2 build.rs generates shaders/dispatch_sys.rs only under `#[cfg(target_os)]` of the HOST. Build on the runner box (minutes vs ~30 min emulated on Mac): copy Dockerfile, .dockerignore, scripts/ and `~/.cache/macos-sdk/MacOSX.sdk.tar.xz` to root@10.4.0.9, then on the host daemon `docker buildx build --load --platform linux/amd64 --build-arg http(s)_proxy=http://192.168.31.199:7890 --build-context macos-sdk=<dir> -t …:N .`; `docker login forgejo.wolf109909.top -u Wtz_LASR --password-stdin` with $VP309_FORGEJO_TOKEN, push, delete SDK copy, `docker logout`. That proxy sometimes cuts transfers: Dockerfile curls use `--retry 5 --retry-all-errors`. CI pulls with `credentials: username: ${{ secrets.BUILDER_USER }}, password: ${{ secrets.BUILDER_TOKEN }}` (webj8-internal member + read:package token; repo secrets in webj8/webjet). webjet keeps its own `scripts/freebsd-sysroot.sh` (freebsd-cargo.sh uses it); keep FREEBSD_VERSION/BASE_SHA256 and now PKGS in sync across both repos. `scripts/macos-sdk.sh` and `ci/builder.Dockerfile` were removed from webjet. Old public images webj8/webjet-builder:1/:2 have no SDK.
