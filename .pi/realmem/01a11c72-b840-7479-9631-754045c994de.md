**Cargo mirror (scripts/cargo-mirror.sh, commits 6eb1d7c, bd616d9, 0de6618; re-tagged c2eda16→bd616d9 after fixes f505ede, 6eb1d7c etc.).** Every job in .forgejo/workflows/ci.yml and release.yml runs it right after checkout. It writes a `[source.crates-io] replace-with = "mirror"` + `[source.mirror] registry` (+ `[registries.mirror] index`) config (as on https://help.mirrors.cernet.edu.cn/crates.io-index/) plus `[net] retry = 10` between `# --- cargo-mirror.sh begin/end` markers in `$CARGO_HOME/config.toml` (builder image: /usr/local/cargo; rerun replaces the block; refuses a foreign crates-io replacement). Before using a source it probes `<index>/config.json` with curl (connect 5 s, max 10 s) and skips it if silent. Source order: `sparse+https://mirrors.tuna.tsinghua.edu.cn/crates.io-index/` → `sparse+https://mirrors.ustc.edu.cn/crates.io-index/` → plain crates.io; each `cargo fetch --locked` is wrapped in `timeout -k 10 $FETCH_TIMEOUT` (default 60 s, user chose 60 over 600); goes through the list up to 3 rounds, 60 s apart; downloads are kept between attempts. Extra args = additional URLs tried in order. Rationale / 2026-10-10 findings on runner box 10.4.0.9: USTC sometimes answers the probe then stalls mid-fetch (no 429 anymore), which with 600 s cost 10 min per job — hence 60 s; earlier USTC gave HTTP 429 Rate limited via proxy 192.168.31.199 (v0.11.4 first tag failed); MirrorZ endpoint mirrors.cernet.edu.cn times out (direct & via proxy; from the Mac it 302s to mirror.nju.edu.cn) and MirrorZ members' sparse indexes lag, but TUNA synced post-`cargo update` versions (tokio-util 0.7.20/zstd 0.14.1) within ~6 h. A cold full fetch from crates.io takes ~61 s, so the first attempt may be cut and the next round finishes it. Run 106 on main (0de6618) used TUNA in ~10-18 s for all 3 jobs and passed; fallback tests: lock behind TUNA → USTC in 41 s; older lock → TUNA in 8 s. Cargo.lock still says crates.io (checksums verified), so --locked and deny.toml `allow-registry = crates.io` keep working. fuzz.yml does not use it. Runner NO_PROXY (/root/docker/forgejo-runner/data/runner-config.yml envs + docker-compose.yml dind env, backups *.bak-20261010003333) includes mirrors.tuna.tsinghua.edu.cn, mirrors.ustc.edu.cn, mirrors.cernet.edu.cn; runner container restarted. v0.11.4 tag deleted and re-created (on bd616d9); release published with 38 assets.
