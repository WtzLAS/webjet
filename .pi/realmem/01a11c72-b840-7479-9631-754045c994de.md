**macOS cross-build.** gpui 0.2.2 build.rs generates shaders/dispatch_sys.rs only under `#[cfg(target_os)]` of the HOST. `scripts/macos-cargo.sh <aarch64|x86_64>-apple-darwin <cargo args>`: plain cargo on Mac; on Linux needs `WEBJET_MACOS_SDK` (CI image sets /opt/macos-sdk/MacOSX.sdk), caches in ~/.cache/webjet-macos-tools: `xcrun` shim (boring-sys `xcrun --show-sdk-path` for bindgen); install_name_tool/otool/lipo → llvm-* (CMake Darwin files FATAL without install_name_tool); `<target>-clang`/`-clang++` wrappers = `clang --target=<arch>-apple-macosx<min> -isysroot SDK -fuse-ld=lld` (+ `-nostdinc++ -isystem SDK/usr/include/c++/v1` for C++) — else CMake links GNU ld ("unrecognised emulation mode: llvm"). Sets SDKROOT, MACOSX_DEPLOYMENT_TARGET (11.0 arm64, 10.12 x86_64); ld64.lld signs arm64 ad hoc so binaries pass `codesign -v`. SDK 27.0 `.tbd` lists `arm64e.x1` rejected by LLVM 20 ld64.lld ("malformed file … unknown architecture"); scripts/macos-sdk.sh picks newest SDK without `arm64e.x*` (26.5). release.sh `build_macos` uses macos-cargo.sh (needs Darwin or WEBJET_MACOS_SDK).

**FreeBSD cross-build (from Mac).** `scripts/freebsd-cargo.sh <cargo args>` runs scripts/freebsd-sysroot.sh, which downloads FreeBSD 14.4-RELEASE base.txz (SHA-256 pinned) into `$WEBJET_FREEBSD_SYSROOT` (default ~/.cache/freebsd-sysroot/x86_64; keeps ./lib ./usr/include ./usr/lib), then sets CC/CXX/AR, sysroot flags, clang linker `-fuse-ld=lld`, `CARGO_BUILD_TARGET`; Homebrew llvm/lld on Mac or `$WEBJET_FREEBSD_LLVM` elsewhere; raises `ulimit -n` to hard limit (max 65536). Boring-sys (default anytls feature) needs `CXXFLAGS_x86_64_unknown_freebsd="--sysroot=$SR -nostdinc++ -isystem $SR/usr/include/c++/v1"` (Homebrew clang headers 'vendor availability markup' → CMake 'Failed to determine … regular expression backend') and `BINDGEN_EXTRA_CLANG_ARGS_x86_64_unknown_freebsd=--sysroot=$SR` (bindgen 'stdlib.h not found'). Binaries need libc++.so.1/libcxxrt (FreeBSD base); highest symver FBSD_1.7 ⇒ FreeBSD 14.0+/OPNsense 24.7+; release.sh build_freebsd dies if binary needs > `FREEBSD_MAX_SYMVER=FBSD_1.7`. First release with FreeBSD artifacts: the one after 0.10.3. No FreeBSD VM/qemu on the Mac — runtime untested. webjet keeps its own scripts/freebsd-sysroot.sh (freebsd-cargo.sh uses it); keep FREEBSD_VERSION/BASE_SHA256 and PKGS in sync across both repos. scripts/macos-sdk.sh and ci/builder.Dockerfile removed from webjet.
