For unit tests that need a real, verifying network state without sockets:
- `crates/webjet-core/src/testutil.rs` (`#[cfg(any(test, feature = "testutil"))]`): `net()` (root/emergency/admin keys + genesis, pool 10.7.0.0/16, admin `alice`), `Cluster` (controller `Machine` + root-certified head key): `enroll(NodeSpec{name, ip, roles, tags, control, routes})`, `data_node(name, ip, tags)`, `admin_op`, `set_network(NetworkConfig)` (bumps all part versions), `set_policy`, `set_node_config`, `head()`, `store()` (a Store with the tree installed), `sync(&mut Store)` (incl. removals). `testutil::packets::{tcp4, udp4}` build checksum-correct IPv4 packets (re-exported as `packet::tests::*`). The policy leaf can only be set via SetNetworkConfig (SetPolicy is retired).
- webjetd dev-deps `webjet-core` with `features = ["testutil"]` + tempfile. `crates/webjetd/src/testnode.rs` (cfg(test)): `node(&mut Cluster, id, kp) -> (Arc<Node>, TempDir)`, `with_store(store, id, kp)`, `sync(&mut cluster, &node)`.
- `Node::test_hop(peer, transport) -> (Arc<Hop>, TestHopRx)` registers a hop without a connection; `TestHopRx::control()` decodes queued HopMsgs, `relay()` gives relay frame payloads.
- `Dataplane::for_test(&n) -> (Arc<Dataplane>, UnboundedReceiver<Vec<u8>>)` (no tun; tun-bound packets arrive on the receiver; installs into `n.dataplane`), `serve_for_test(grant)`. `Sessions::queued_for_test(peer)` shows (ftype, payload) queued before a handshake.
- Controller: `Controller::start(&n, true)` with a bare genesis store, then `raft.lock().tick(now+10s)` twice + `apply_committed` makes a single-voter leader; first entries are leader no-op (1) then genesis (2) after `leader_duties()`.
- `webjet-tools/tests/root.rs` runs the real `webjetctl root` binary with `WEBJET_ROOT_PASSPHRASE`/`WEBJET_BACKUP_PASSPHRASE` env.
- Pitfall: in `prop_assert!` messages, braces in the condition text (`Key { .. }`, `if x { } else { }`, `format!("{a}")`) break the macro's format string; bind to a variable first.
