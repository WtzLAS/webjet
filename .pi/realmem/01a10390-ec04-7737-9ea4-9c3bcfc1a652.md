Every network setting has a built-in default (commit after 45997b1):
- `webjetctl {transport,dns,seeds,limits,policy} show` (crates/webjet-tools/src/show.rs) print the setting in force as the YAML that `apply` reads, with built-in defaults and `version: 0` plus a `# No … applied yet` header when nothing was applied; `--json` prints the same document as JSON. The camouflage certificate appears only as PEM in comments (apply reads it from a file). The control call `tree` now also returns `policy` (wire form, kept in `View::policy_wire`), `resolver` (in force) and `suffix`.
- Limits: the single table is `webjet_core::validate::LIMITS` (name, default, description; `relay_capacity_mbps` and `rate_ceiling_mbps` default to unset). `View::limit(me, name) -> Option<u64>` and webjetd `metrics::limit(n, name)` / `limit_opt` read it (local `[limits]` > tree overrides (highest) > tree defaults > built-in). All 17 are enforced, with the spec's §16.2 numbers: circuits 64/source and 10 setups/s per source (was 256 and 200/s per relay), SNAT limits = conntrack gateway flows (`Conntrack::insert(.., gateway, ..)`, errors SnatPeerQuota/SnatGlobal count `snat_exhausted`), e2e handshakes per sec/global and handshake_queue, hop_handshakes_per_ip (TCP listeners via `transport::HandshakeGate`, KCP via `UdpEndpoint::per_ip_limit`), lookups_per_sec, subscriptions_per_peer, rate_ceiling from the tree too. Transport-layer limits re-applied on HeadChanged (`transport::apply_limits`), conntrack limits on dataplane refresh. `e2e_handshakes_in_progress` is met trivially (one handshake per session).
- DNS resolver default: `View::resolver_ips(pool)` = DnsConfig `resolver_ip`, else per family the highest host of the first overlay pool not held by a node (10.7.0.0/16 → 10.7.255.254; IPv6 hosts() includes the all-ones address). The state machine reserves it (enrollment of that IP is rejected) — deterministic, so all controllers must run this version.
- Padding: `padding::DEFAULT_LINES`/`DEFAULT_STOP`; hop writers now use the TransportConfig's padding scheme when set (before, always the built-in).
