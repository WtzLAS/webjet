Before committing in Webjet run: `cargo fmt`, `cargo clippy --workspace --all-targets`, same with `--no-default-features`, `cargo test --workspace`; all must be warning-free (user requires clean clippy including tests). Workspace lints warn on `clippy::unwrap_used`/`expect_used`; `clippy.toml` allows them in tests. Parse untrusted bytes with checked readers in `crates/webjet-core/src/bytes.rs` (return None), sort floats with `total_cmp`. Generated `webjet-proto/src/generated.rs` is `#[rustfmt::skip]` + lint-allowed in lib.rs; never hand-edit. Platform-only code (`cfg(target_os="linux")`, `cfg(windows)`) isn't seen by macOS clippy: check Linux via `docker run rust:1-bookworm cargo clippy ...` and Windows via `cargo xwin clippy --target x86_64-pc-windows-msvc -p webjetd -p webjet-tools --no-default-features` (needs `brew install llvm`, PATH=/opt/homebrew/opt/llvm/bin). pi-lens `rust-unwrap` tree-sitter rule also flags unwraps inside #[cfg(test)] modules (false positives; clippy is authoritative).
