`crates/webjet-core/src/packet.rs`: `Parsed` has `fragment: Fragment::{Whole, First, Later}`. Later fragments have no L4 header (ports 0, `l4_offset` = payload): `rewrite` never writes ports into them, `fix_checksums` skips L4 checksums for any fragment, `icmp_unreachable` doesn't answer later fragments (RFC 1122).

Mapped gateways (1:1 prefix mapping, §11.9.2) use `packet::map_addrs(p, src, |a| map_prefix(a, from, to))`, NOT `rewrite`. It changes addresses only and updates the L4 checksum incrementally (RFC 1624 `adjust_checksum`), so first fragments stay valid. For ICMP errors it maps the quoted packet's opposite address with the same function and keeps quoted ports. Before this fix, `rewrite(p, Some((ps, parsed.flow.sport)), None)` set the quoted port to 0 (ICMP errors have sport/dport 0), which broke PMTUD and port-unreachable through mapped gateways. Callers: `webjetd/src/dataplane.rs` (LAN→overlay return path and overlay→LAN). Proptests: `map_addrs_keeps_ports_and_checksums`, `map_addrs_follows_icmp_quotes`, `later_fragments_keep_their_payload`.
